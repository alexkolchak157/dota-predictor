# Dota 2 Match Predictor

Прототип предиктивной модели исходов про-матчей Dota 2: Glicko-2 рейтинги по отдельным игрокам, feature engineering без утечек из будущего, LightGBM с калибровкой вероятностей и честная временная валидация.

## Структура

| Файл | Что делает |
|---|---|
| `glicko2.py` | Реализация Glicko-2. Рейтинги считаются на игроков, рейтинг команды — композит состава, поэтому стенд-ин корректно меняет прогноз |
| `data_loader.py` | Загрузка про-матчей и составов из OpenDota API (запускать у себя, нужен интернет) |
| `features.py` | Фичи: вероятность по Glicko-2, разница рейтингов, неопределённость (RD), форма за 10 карт, сглаженный H2H, дни отдыха, опыт составов. Строго хронологический проход |
| `model.py` | Сравнение baseline → чистый Glicko-2 → LightGBM + изотоническая калибровка. Метрики: log-loss, Brier, accuracy |
| `synthetic.py` | Синтетический «мир» с известными истинными вероятностями — для самопроверки пайплайна и расчёта теоретического предела log-loss |
| `main.py` | Точка входа |

## Запуск

```bash
pip install lightgbm scikit-learn pandas numpy requests

# 1. Самопроверка на синтетике (без интернета)
python main.py

# 2. Реальные данные
python data_loader.py            # скачает matches.csv + details.csv (~1-2 часа из-за rate limit)
python main.py details.csv
```

## Результаты самопроверки (синтетика, 6000 матчей)

```
Теоретический предел (оракул):  log_loss 0.494
baseline 50/50:                 log_loss 0.693   acc 0.551
glicko2 only:                   log_loss 0.541   acc 0.730
lgbm + isotonic:                log_loss 0.545   acc 0.731
```

Glicko-2 почти достигает предела мира — пайплайн исправен. На синтетике бустинг **не обгоняет** чистый Glicko-2, и это ожидаемо: в игрушечном мире рейтинг — почти достаточная статистика, остальные фичи там шум. На реальных данных расклад другой: там появляются сигналы, которых у Glicko-2 нет (патчи, драфты, карты, LAN/онлайн), и именно их добавление — смысл слоя бустинга.

## Куда развивать

1. **Данные**: догрузить патч, лигу (tier), драфт героев; для CS2 — тот же каркас, но фичи по картам (винрейт на карте из пула — главный сигнал).
2. **Фичи**: рейтинг по ролям (керри/саппорт), синергия пар игроков, embedding героев.
3. **Модель**: Optuna для гиперпараметров, walk-forward валидация вместо одного split, ансамбль с логистической регрессией.
4. **Калибровка**: смотреть calibration curve на тесте — для прогнозов важнее accuracy.

## Честные ожидания

Реалистичный потолок на реальной про-сцене — accuracy ~0.63–0.70 и log-loss ~0.58–0.62 в зависимости от tier матчей. Модель такого уровня **не обыгрывает** закрывающую линию букмекера (см. обсуждение выше) — это аналитический и учебный инструмент.

## Данные в репозитории

`details.csv` (~2500 про-матчей, OpenDota) коммитится в репо осознанно: данные публичные, файл лёгкий, и это делает результаты воспроизводимыми без ожидания квоты API. Дневная квота бесплатного тарифа — 2000 запросов; загрузчик умеет докачивать с места остановки (`python data_loader.py` на следующий день продолжит сам).
